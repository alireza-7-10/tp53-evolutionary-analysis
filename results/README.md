# Results

This folder contains the output files of the TP53 evolutionary analysis.

## Contents
- **Figure1_Phylogenetic_Tree.png**: Maximum Likelihood phylogenetic tree of TP53 CDS across seven vertebrate species (Tamura-Nei model, 1000 bootstrap replicates).
- **Figure2_FEL_Plot.png**: Plot of estimated synonymous (α) and nonsynonymous (β) substitution rates at codon sites based on FEL analysis (Datamonkey server).
- **genetic_distance_matrix.csv**: Pairwise genetic distance matrix calculated based on the Tamura-Nei model.
